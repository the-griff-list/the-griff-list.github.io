This package version uses LiveKit Cloud and the Cloudflare Worker token endpoint. It does not require MediaMTX, WHIP, WHEP, Docker, Caddy, router port forwarding, or a self-hosted media server.

IMPORTANT: REVIEW BEFORE DEPLOYING
