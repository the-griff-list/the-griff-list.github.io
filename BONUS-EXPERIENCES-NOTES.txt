THE GRIFFLIST - SECRET MENU AND PUBLIC FEATURES

- Secret Menu opens from one clearly labelled footer button.
- PS2 boot-up plays once on entry. Homepage menu music pauses during the Secret Menu and resumes on close if it was previously playing.
- PS2 effects are used for menu selection, guitar-pick pickup, transition, Lost Cassette discovery, and randomized high-score celebrations.
- No Secret Menu background music or sound-mode dropdown is used.
- Guitar Pick Panic mini-game stores a local personal-best score.
- Explore contains Crowd Favourites, Encore Vote, and the Rock Wall.
- The Rock Wall shows only confirmed real tip records; it never invents donors or tip amounts. Admin must verify payments before recording tips.
- Day, Gothic Night, and neon 80s modes apply to public pages only.
- Seasonal holiday mode is intentionally deferred until the final design review.
- PWA offline cache contains static site assets. Online requests, tip updates, and live video still require connectivity.
- Supabase migrations are included but must be run manually in the Supabase SQL Editor if not already applied.
