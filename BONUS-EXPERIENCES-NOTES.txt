THE GRIFFLIST — BONUS EXPERIENCES UPDATE

IMPLEMENTED IN THIS PACKAGE
- Discreet music-note button at the bottom opens the Secret Stage. No secret code required. Tell people where to find the note.
- Secret Stage reveal animation respects reduced-motion preferences.
- Lost Cassette teaser panel (ready for your chosen recording/story later).
- Backstage Arcade: Guitar Pick Panic mini-game with a local personal-best score.
- Hidden Note message.
- Setlist Roulette (animated song picker) and Surprise Me (immediate random song); these are distinct actions.
- Pick Your Rock Era filter linked to the repertoire decade filter.
- Day, Night, and Neon visual themes, saved on that visitor's device.
- Song-request confirmation animation and existing success sound.
- Downloadable/shareable song card; native share is used where supported.
- Grifflist Time Machine built from dated repertoire entries.
- Monthly seasonal feature prompt.
- Confirmed-tip wall: display name, amount, optional requested song; no dates are displayed. Tips must be verified and added by admin; no payment provider webhook is configured.
- UI sound theme selector is prepared. The PS2-inspired audio files are not included yet; send your legally usable audio files when ready.
- Installable PWA manifest and offline cache for local website assets/repertoire shell. Online requests, confirmed-tip updates, and live video still need connectivity.
- Main bonus interactions are folded into existing site-interactions.js to avoid an extra script file.

TIP WALL SETUP
1. Open Supabase SQL Editor.
2. Run bonus-features-migration.sql once.
3. Verify the admin UUID in the SQL matches your own authorized admin account before running.
4. In Admin, add a tip only after confirming the payment in the relevant provider/bank. The public wall does not show dates, payment IDs, or legal names unless you deliberately enter a full name as the display name. Prefer a nickname or Anonymous Rocker.

PWA / OFFLINE NOTES
- The app must be served over HTTPS (GitHub Pages qualifies).
- Open the site online once so the service worker can cache the core files. Then test offline mode.
- The browser's own install prompt is not available in every browser; Android users can also use the browser menu > Install app / Add to Home screen.
- The service worker caches the local repertoire interface, not Supabase data or the live stream.
