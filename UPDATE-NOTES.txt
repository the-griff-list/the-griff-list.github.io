THE GRIFFLIST — TITLE SCREEN, AUDIO CROSSFADE, AND NAVIGATION UPDATE

What's changed:
- Title screen now combines the hand-drawn guitarist artwork with the refreshed metallic Grifflist logo in the original side-by-side layout.
- The title prompt is separate from the image so it can fade in and out; it is centered under the logo, larger, and bold for mobile readability.
- Title audio is attempted on page load (autoplay may be blocked by mobile browsers until a tap).
- After the visitor taps the title screen, menu music starts only after that interaction. The title and menu tracks crossfade together over about 1.6 seconds when timing allows.
- Menu music pauses when the browser tab/app is hidden and resumes only after the visitor has entered the site and returns to the page.
- Main navigation order follows the visitor journey: Song Catalog → Make a Request → Support the Show → Encore Vote → Booking & Contact.
- Main toolbar links continue to play a randomly selected UI sound. Support actions, song selections, email copying, scrolling, and successful actions retain their assigned effects.
- Rock Meter red/yellow/green images, support links, song catalog, request form, encore voting, and private Request Archive files are retained.
- Star Power cheer files are not included.

INSTALL:
1. Extract the ZIP.
2. Upload all included files to the root of the existing GitHub Pages repository, replacing matching files.
3. Commit to main and wait for GitHub Pages to publish.
4. Test the title screen, audio transition, toolbar sounds, support section, song catalog, and archive on mobile.

NOTES:
- Mobile browsers can block autoplay. The title track is attempted on page load and is retried when the visitor taps the title screen if playback was blocked.
- Menu music is paused when the page becomes hidden. Audio playback and exact volume balance can vary by device/browser.
- The Rock Meter reflects the existing Supabase configuration; automatic verified Ko-fi/PayPal payment tracking requires separate payment-provider integration.
- The package has not been deployed to or tested against the live GitHub Pages site.
