AUDIO PERFORMANCE UPDATE — LIGHTWEIGHT PLAYBACK
- Re-encoded all 16 local MP3 audio assets with smaller, web-friendly bitrates. Short interface effects use approximately 48 kbps mono; the success sound uses 64 kbps mono; title and boot sounds use 80–96 kbps; normal menu ambience uses 96 kbps stereo; the 10-minute Secret Stage ambience uses 64 kbps stereo.
- Combined local MP3 size is now approximately 6.4 MB. The Secret Stage ambience is approximately 4.6 MiB, down from about 7.0 MiB in the previous package and much smaller than the supplied original.
- Audio elements and scripted sound effects use preload="none" so the browser doesn't download every sound when the homepage first loads. Sounds download when they are played.
- The service worker no longer downloads every audio file during initial installation. It caches assets after they are requested online, so audio already played can be available offline; first-time playback of an uncached sound still requires a connection.
- Audio is lossy-compressed, so it is not bit-for-bit identical to the originals. Settings prioritize a reasonable balance of sound quality and size, with stereo preserved for background tracks.
- Existing title/menu behavior, Secret Stage boot-then-ambience behavior, and sound controls remain unchanged. Test playback on mobile and desktop after publishing.

- Request form name field label now reads “Name (Required)” to make the required field clearer.
