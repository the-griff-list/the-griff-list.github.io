THE GRIFFLIST — CATALOG & REQUEST UPDATE

Upload every file in this folder to the ROOT of the GitHub repository, replacing the existing files. Do not upload this folder as a nested folder.

Files included:
- index.html
- styles.css
- script.js
- splash-screen.webp
- select.mp3 (site navigation/select sound)
- title-screen-sound.mp3 (UI Sound 06R for the splash-screen entry)

Changes in this update:
- Request SMS contains only the person's name, the song title in quotation marks, artist (when entered), and optional comments. No heading, labels, queue text, or other wording.
- The splash screen has a single pulsing “PRESS ANY BUTTON TO ROCK” prompt overlay.
- Booking email and e-transfer email can each be copied with one tap.
- Removed the 50s decade filter and “Highway to Hell” from the catalog.
- Removed the play icon from catalog rows; tapping anywhere on a song row fills the request form and scrolls to the request section. No song details popup.
- The original select.mp3 remains for site navigation; title-screen-sound.mp3 is separate for the splash screen.

Important limitations:
- On GitHub Pages, SMS opens the visitor's messaging app with the request prefilled. They must press Send. Automatic sending requires a separate SMS service.
- YouTube search links / inline playback are not part of this particular change; the catalog play icons are removed as requested.
