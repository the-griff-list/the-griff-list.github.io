THE GRIFFLIST — WEBSITE UPDATE (OCTOBER 27)

1. Extract this ZIP on your device.
2. Open https://github.com/the-griff-list/the-grifflist
3. Upload the files in this ZIP to the repository ROOT (not inside a new folder), replacing files with matching names.
4. Commit the changes to the main branch.
5. In the repository, open Settings → Pages and confirm the site publishes from main / (root).
6. Wait for GitHub Pages to finish publishing, then open https://the-griff-list.github.io/the-grifflist/ and refresh.

WHAT'S UPDATED
- Encore admin accepts TWO or THREE options. Leave Song option 3 blank for a two-option vote.
- The public encore vote and Rock Meter refresh every 8 seconds while the page is visible, and refresh immediately when you return to the tab.
- Asset version strings are bumped to help browsers load the latest CSS and JavaScript instead of old cached files.
- Navigation has a more Guitar Hero-inspired, metallic menu style and button animations.
- The splash prompt is positioned over the splash artwork and uses a bold condensed fallback font with a pulsing animation. The exact proprietary in-game font file is not included.
- Support links and buttons trigger the existing title-screen MP3 sound effect, subject to browser sound/autoplay settings.
- The private request dashboard uses larger, stage-readable text.

IMPORTANT
- Keep supabase-config.js as included. Never put a Supabase secret/service_role key in this public repository.
- The live features require the separate Supabase live-features SQL migration to have been run successfully.
- The browser checks for new Rock Meter and encore data every 8 seconds; this is near-live polling, not instant database push.
- If an item still appears old after deployment, open the site in a private/incognito tab or hard refresh, then verify that the commit completed and Pages deployed it.
